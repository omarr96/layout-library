Frequently asked questions

Common questions about authentication, limits, webhooks and billing for the Parcelwire email & SMS API. For the full reference, see the API docs.

Send your secret key as a Bearer token. Create keys under Settings → API keys; they're shown once, so store them in an environment variable.

bash
# Send a test email
curl https://api.parcelwire.dev/v3/emails \
  -H "Authorization: Bearer $PARCELWIRE_KEY" \
  -H "Content-Type: application/json" \
  -d '{"to":"ada@example.com","subject":"Hello","text":"It works"}'

Never put secret keys in browser or mobile code — use a restricted publishable key instead.

Free projects get 10 requests/second; Pro gets 100 and Scale gets 1,000. Every response includes X-RateLimit-Remaining and X-RateLimit-Reset.

If you go over, you'll get a 429 with a Retry-After header in seconds. Our SDKs back off and retry automatically, up to 3 times.

Each webhook carries a Parcelwire-Signature header: an HMAC-SHA256 of timestamp.body using your endpoint's signing secret. Reject requests older than 5 minutes.

node.js
import crypto from "node:crypto";

export function verify(rawBody, header, secret) {
  const [t, sig] = header.split(",").map(p => p.split("=")[1]);
  if (Date.now() / 1000 - Number(t) > 300) return false;
  const expected = crypto.createHmac("sha256", secret)
    .update(`${t}.${rawBody}`).digest("hex");
  return crypto.timingSafeEqual(Buffer.from(sig), Buffer.from(expected));
}

Add an Idempotency-Key header (any unique string, e.g. your order ID). If we see the same key within 24 hours, we return the original response instead of sending again.

python
from parcelwire import Client

client = Client()
client.emails.send(
    to="ada@example.com",
    idempotency_key=f"order-{order.id}",
)

The first 3,000 emails a month are free. After that, emails are $0.80 per 1,000 and SMS is priced per country (from $0.0079 per segment in the US). You're billed monthly in arrears, and you can set a hard spend limit in the dashboard.

Official SDKs for Node.js, Python, Go, Ruby and PHP, all typed and open source under MIT. Anything else can call the REST API directly; there's an OpenAPI 3.1 spec to generate your own client.

bash
npm install @parcelwire/node

Choose EU (Frankfurt) or US (Virginia) when you create a project; data never leaves that region. Message bodies are kept for 30 days for debugging, then deleted. Delivery metadata is kept for 13 months.
