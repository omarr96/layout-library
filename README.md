# Design Library

HTML design mockups, one folder per design. Open `index.html` to browse them all.

## Folders

| Folder | What's in it |
|---|---|
| `site-builder/` | Editor, AI builder and builder panels |
| `site-dashboard/` | Site overview, publishing, domains and MCP |
| `woocommerce/` | DiviMerc shop, product grids and carousels |
| `checkout-account/` | Checkout, thank-you and customer account |
| `admin-support/` | Dashboards, tickets and admin UI |
| `landing-pages/` | Single page sites |
| `mobile/` | Android themes and app mockups |

Each design lives at `<category>/<design>/index.html`. Extra versions of the same design sit next to it (for example `connect-model/minimal.html`).

## Adding a design

1. Put the page in `<category>/<design-name>/index.html`.
2. Add an entry to `designs.js` with its title, description, tags, date and pages.
3. Commit and push. If GitHub Pages is on, the gallery updates in a minute or two.

## Viewing

Open `index.html` in a browser, or turn on GitHub Pages (Settings → Pages → deploy from the `main` branch, root folder) to get a shareable link.
