FAQ

Questions, answered

Does it work with my theme?

Yes. Product Grid is a Divi 5 module, so it works anywhere the Divi builder does: pages, the Theme Builder and shop templates.

Can I use my own card design?

Start from any layout and change spacing, borders, colours, fonts and hover effects. You can also save your version as a new layout and reuse it.

Will it slow my store down?

Only the CSS and JavaScript for the parts you turn on are loaded, and images are lazy loaded with the right size for each column count.

Do swatches need another plugin?

No. Swatches are read from your product variations. Colour attributes show as dots, others as small labels.
